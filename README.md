# Shashwat Portfolio — React Native / Expo

## Background correction

The supplied original artwork is **1920×1080**.

For the reference portfolio composition, the artwork is intentionally
compressed vertically to **1920×660**. This is not a crop: the entire
original circuit artwork is retained.

The green lower circuitry therefore moves upward into the hero instead of
remaining underneath the Skills/Connect section.

The hero is also 660px tall so the image is displayed 1:1 with the adjusted
asset.

Run:

```bash
npm install
npx expo start
```
